# agentboard v0.1.3 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 三个体验增强：横幅点击直接跳回该会话、会话行内显示"在等什么"、需处理条目可消除。

**Architecture:** 在既有采集→状态机→呈现链路上做加法：UnifiedEvent::Waiting 增带 reason 字段贯穿到前端；machine 增 dismissed 抑制；通知横幅增"跳回会话"动作（视插件能力）。

**Tech Stack:** 不变（Tauri 2 + Rust + React；可能新增 tauri-winrt-notification 直用）。

**Spec:** 沿用 docs/superpowers/specs/2026-11-17-agentboard-design.md + docs/reference/pitwall-analysis.md 的功能映射。

## Global Constraints

- 既有铁律全部有效：hook 永不阻塞、无网络、推不出不硬标、通知不含请求内容（**reason 是工具摘要/等待原因，属 Pitwall 验证过的"告诉用户在等什么"例外，照其 120 字截断设计**）
- 每任务 cargo test --release + vitest 全绿 + fmt 干净 + commit；版本号最终 bump 到 0.1.3
- 磁盘紧张：build 前 df，os error 112 删 src-tauri/target/debug/{incremental,build}
- gh 操作需 `export HTTPS_PROXY=http://127.0.0.1:7897`

### Task 3: 横幅点击直接跳回会话

**Files:** Modify `src-tauri/src/lib.rs`、`Cargo.toml`（可能）、`README.md`（交互说明）

**Interfaces:**
- Produces: 横幅含「打开看板」主体点击（现有 tap→show_main 保持）+ 若 crate 支持 toast 按钮：按钮「跳回会话」→ 直接 `platform::jump_payload(snapshot)` 执行（spawn+clipboard，不打开看板）

**调查步骤（必须先做，报告附证据行号）：**
1. 读 registry 里 tauri-plugin-notification 2.8.1 源码：Rust Notification builder 是否支持**每条通知的按钮**（action with label+id）与 per-toast 回调（而非全局 on_action）。grep `fn action` / `actions` / `buttons`
2. 若插件不支持 → 检查 `tauri-winrt-notification` crate（notify-rust 系）：`Toast::new(aumid).action(label, id)` + per-toast `on_action/on_activated` 是否可用；可用则 send_notification 改用它（AUMID 仍 "com.agentboard.app"），tauri-plugin-notification 保留注册不动（其 on_action 全局 handler 处理 tap→show_main 不变；注意两套并存时同一 toast 只能由一套发——按钮路线的 toast 由直用 crate 发，tap 路线 toast 保持插件发：**裁定：send_notification 整体切到 tauri-winrt-notification**（含按钮+主体回调），插件仅剩 npm/权限注册不拆）
3. 若两 crate 都不支持按钮 → 降级方案：主体 tap 的全局 handler 维持 show_main，**额外** emit 一个 `last-notified-session` Tauri 事件给前端；前端收到后高亮该行并在窗口聚焦时滚动到位（"直达"降级为"聚焦定位"），报告说明降级原因

- [ ] Step 1: 调查（附行号证据）→ 按裁定实现：跳回动作带 session_id（jump_payload 全链复用，含 clipboard 与 wt/explorer），按钮文案「跳回会话」；主体点击仍 show_main
- [ ] Step 2: 版本 bump：tauri.conf.json / package.json / Cargo.toml → 0.1.3
- [ ] Step 3: 全绿 + `npm run tauri build`（先 taskkill）→ commit `feat(v0.1.3): 横幅按钮直接跳回会话 + 版本 0.1.3` + push
